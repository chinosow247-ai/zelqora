ZELQORA V5 — CORE SOCIAL APP STARTER

Run:
1. npm install
2. npm start
3. Open http://localhost:3000

Added over V4:
- Persistent JSON database (data.json)
- User profiles and profile editing
- User search
- Private one-to-one chat with persistent messages
- Notifications
- Video feed metadata
- Video publishing by URL
- Likes and comments
- Existing wallet, premium test mode, creator gifts and payout prototype retained
- Mobile-friendly navigation

IMPORTANT:
This is still a development starter, not a production deployment. For production,
replace data.json with a managed database, add object storage/video processing,
HTTPS, secure secrets, rate limits, moderation, abuse reporting, account recovery,
email/phone verification, WebSocket realtime delivery, backups, monitoring,
and real payment/store billing integration.
