# Observability

Minimum production monitoring:
- `/api/health` uptime check.
- `/api/ready` readiness check.
- Server CPU/RAM/disk monitoring.
- Upload storage capacity alerts.
- Error-rate and latency tracking.
- WebSocket connection/error monitoring.
- Backup success/failure alerts.
- Security alerts for repeated authentication failures.

Keep logs free of passwords, JWTs, device tokens and unnecessary personal data.
