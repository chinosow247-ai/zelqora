# Zelqora content-safety launch checklist

- Report video, comment, profile and message abuse.
- Block users and prevent blocked-user messaging.
- Admin queue for reports with status/history.
- Copyright/takedown request process.
- Repeat-offender escalation and account suspension.
- Clear prohibited-content rules and appeals process.
- Age-appropriate defaults and safeguards.
- Rate limits and anti-spam controls.
- Audit logs for moderator actions.
- Emergency escalation contact for serious safety issues.
