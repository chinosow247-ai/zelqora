# Install Zelqora on a phone now

Zelqora includes a Progressive Web App (PWA) manifest and service worker.

1. Deploy the web app behind HTTPS.
2. Open the Zelqora URL in Chrome on Android or Safari on iPhone.
3. Android: browser menu -> Add to Home screen / Install app.
4. iPhone: Share -> Add to Home Screen.

This creates an app-like Zelqora icon without waiting for Google Play or the App Store.
